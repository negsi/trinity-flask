## 1. Base URL & Conventions

- **Base Path:** `/api/v1`
- **Content-Type:** `application/json` (unless specified otherwise for multipart/form-data uploads).
- **Error Handling:** Errors return structured JSON payloads with HTTP status codes (`400 Bad Request`, `404 Not Found`, `500 Internal Server Error`).

## 2. Agents Endpoints (`/api/v1/agents`)

Manage autonomous AI agents, their system prompts, and memory configurations.

<details>
<summary><code>POST</code> <strong>/api/v1/agents</strong> — Create a new agent</summary>

<br>

**Description:**  
Creates a new AI agent instance in the system database.

**Request Body (`CreateAgentRequest`):**
```json
{
  "name": "Research Assistant",
  "system_prompt": "You are a helpful researcher. Extract useful facts.",
  "description": "Specialized in web search and synthesis",
  "group_ids": ["grp-uuid-1234"],
  "memory_enabled": true,
  "memory_mode": "user_only",
  "memory_limit_type": "message_count",
  "memory_message_count": 10
}
```

| Field | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `name` | `string` | **Yes** | — | Agent name (1–100 characters). |
| `system_prompt` | `string` | No | `null` | Custom system instruction prompt for the LLM. |
| `description` | `string` | No | `null` | Short summary (max 500 characters). |
| `group_ids` | `string[]` | No | `[]` | List of group UUIDs to associate. |
| `memory_enabled` | `boolean` | No | `false` | Master switch for conversation memory. |
| `memory_mode` | `string` | No | `"user_only"` | History filter: `"user_only"` or `"all"`. |
| `memory_limit_type` | `string` | No | `"all"` | Truncation strategy: `"all"` or `"message_count"`. |
| `memory_message_count` | `integer` | No | `null` | Max retained messages (required if limit type is `message_count`). |

**Responses:**
- **`201 Created`**: Returns the serialized agent dictionary (`Agent.to_dict()`).
- **`400 Bad Request`**: Validation error if required fields are missing or constraints are violated.

</details>

<details>
<summary><code>GET</code> <strong>/api/v1/agents</strong> — List all agents</summary>

<br>

**Description:**  
Retrieves all registered agents ordered by recent activity.

**Responses:**
- **`200 OK`**: Returns a JSON array of agent objects.

</details>

<details>
<summary><code>PUT</code> <strong>/api/v1/agents/{agent_id}</strong> — Update an agent</summary>

<br>

**Description:**  
Updates metadata, system prompts, or memory configurations for an existing agent.

**Path Parameters:**
- `agent_id` (`string`): Unique UUID of the agent.

**Request Body (`UpdateAgentRequest`):** *(All fields optional for partial updates)*
```json
{
  "name": "Updated Assistant Name",
  "memory_message_count": 15
}
```

**Responses:**
- **`200 OK`**: Returns the updated agent dictionary.
- **`404 Not Found`**: Agent does not exist.

</details>

<details>
<summary><code>DELETE</code> <strong>/api/v1/agents/{agent_id}</strong> — Delete an agent</summary>

<br>

**Description:**  
Permanently deletes an agent and its associated datasources.

**Path Parameters:**
- `agent_id` (`string`): Unique UUID of the agent.

**Responses:**
- **`204 No Content`**: Successfully deleted.
- **`404 Not Found`**: Agent not found.

</details>

## 3. Agent Groups Endpoints (`/api/v1/groups`)

Manage organizational groups of agents.

<details>
<summary><code>POST</code> <strong>/api/v1/groups</strong> — Create a group</summary>

<br>

**Request Body (`GroupRequest`):**
```json
{
  "name": "DevOps Squad",
  "description": "Agents specialized in CI/CD and infrastructure"
}
```

**Responses:**
- **`201 Created`**: Returns the created group object.
- **`400 Bad Request`**: Validation error.

</details>

<details>
<summary><code>GET</code> <strong>/api/v1/groups</strong> — List all groups</summary>

<br>

**Responses:**
- **`200 OK`**: Returns an array of all groups including member counts.

</details>

<details>
<summary><code>PUT</code> <strong>/api/v1/groups/{group_id}</strong> — Update group metadata</summary>

<br>

**Request Body (`GroupRequest`):** Name and description.  
**Responses:** `200 OK`, `404 Not Found`.

</details>

<details>
<summary><code>DELETE</code> <strong>/api/v1/groups/{group_id}</strong> — Delete a group</summary>

<br>

**Description:** Deletes the group container (agent associations are removed, agents themselves remain).  
**Responses:** `204 No Content`, `404 Not Found`.

</details>

<details>
<summary><code>PUT</code> <strong>/api/v1/groups/{group_id}/agents</strong> — Assign agents to group</summary>

<br>

**Request Body (`AssignAgentsRequest`):**
```json
{
  "agent_ids": ["uuid-agent-1", "uuid-agent-2"]
}
```

**Responses:**
- **`200 OK`**: Associations updated successfully.

</details>

## 4. Agent Knowledge Base & Datasources (`/api/v1/agents/{agent_id}/datasources`)

Upload reference documents into an agent's knowledge base.

<details>
<summary><code>POST</code> <strong>/api/v1/agents/{agent_id}/datasources</strong> — Upload datasource</summary>

<br>

**Description:**  
Uploads a document via `multipart/form-data` and links it as a knowledge source to the agent.

**Form Parameters:**
- `file` (File Blob, **Required**): The document file (PDF, TXT, MD, JSON).
- `name` (string, Optional): Custom display name.

**Responses:**
- **`201 Created`**: Returns the created datasource entity object.
- **`400 Bad Request`**: `NO_FILE_PART` or `NO_SELECTED_FILE`.
- **`404 Not Found`**: Agent not found.

</details>

<details>
<summary><code>DELETE</code> <strong>/api/v1/agents/{agent_id}/datasources/{datasource_id}</strong> — Delete datasource</summary>

<br>

**Responses:**
- **`200 OK`**: `{"message": "Datasource successfully deleted", "id": "..."}`
- **`404 Not Found`**: Agent or datasource not found.

</details>

## 6. Real-Time Streaming & Chat (`/api/v1/agents/{agent_id}/stream`)

<details>
<summary><code>POST</code> <strong>/api/v1/agents/{agent_id}/stream</strong> — Stream agent response (SSE)</summary>

<br>

**Description:**  
Persists incoming user messages (with optional file attachments via `multipart/form-data` or `application/json`) and streams real-time LLM execution tokens and tool task chain events using Server-Sent Events (SSE).

**Request Body (JSON Example):**
```json
{
  "text": "Fetch recent news and summarize them.",
  "conversation_id": "conv-uuid-1234"
}
```

| Field | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `text` or `message` | `string` | Yes* | `""` | User prompt text. |
| `conversation_id` | `string` | No | `null` | Target conversation UUID (auto-generated if omitted). |
| `files` | `file[]` | No | `[]` | Optional file attachments (sent via `multipart/form-data`). |

*\* Either text or files must be provided.*

**Response Stream (W3C Server-Sent Events):**
```text
data: {"type": "meta", "data": {"conversation_id": "conv-uuid-1234", "user_message_id": "msg-999"}}

data: I am analyzing your request and planning the task chain...
data: • Step 1: Executing web search...
data: • Step 2: Summarizing results...

```

</details>

## 7. Sandbox File Serving (`/api/v1/chat`)

<details>
<summary><code>GET</code> <strong>/api/v1/chat/conversations/{conversation_id}/files/{filename}</strong> — Download sandbox file</summary>

<br>

**Description:**  
Serves generated files (such as reports, ODF documents, or generated images) directly from the conversation sandbox folder as attachments.

**Path Parameters:**
- `conversation_id` (`string`): Conversation UUID.
- `filename` (`string`): Relative filename or path inside the conversation workspace.

**Responses:**
- **`200 OK`**: Binary file stream (`as_attachment=True`).
- **`404 Not Found`**: File does not exist.

</details>
