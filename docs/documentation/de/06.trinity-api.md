## 1. Basis-URL & Konventionen

- **Basispfad:** `/api/v1`
- **Content-Type:** `application/json` (sofern für Multipart/Form-Data-Uploads nicht anders angegeben).
- **Fehlerbehandlung:** Fehler geben strukturierte JSON-Nutzdaten mit HTTP-Statuscodes zurück (`400 Bad Request`, `404 Not Found`, `500 Internal Server Error`).

## 2. Agenten-Endpunkte (`/api/v1/agents`)

Verwaltung autonomer KI-Agenten, ihrer System-Prompts und Speicherkonfigurationen.

<details>
<summary><code>POST</code> <strong>/api/v1/agents</strong> — Neuen Agenten erstellen</summary>

<br>

**Beschreibung:**  
Erstellt eine neue KI-Agenten-Instanz in der Systemdatenbank.

**Anfragetext (`CreateAgentRequest`):**
```json
{
  "name": "Research Assistant",
  "system_prompt": "You are a helpful researcher. Extract useful facts.",
  "description": "Specialized in web search and synthesis",
  "group_ids": ["grp-uuid-1234"],
  "memory_enabled": true,
  "memory_mode": "user_only",
  "memory_limit_type": "message_count",
  "memory_message_count": 10
}
```

| Feld | Typ | Erforderlich | Standard | Beschreibung |
| :--- | :--- | :--- | :--- | :--- |
| `name` | `string` | **Ja** | — | Agentenname (1–100 Zeichen). |
| `system_prompt` | `string` | Nein | `null` | Benutzerdefinierter Systemanweisungs-Prompt für das LLM. |
| `description` | `string` | Nein | `null` | Kurze Zusammenfassung (max. 500 Zeichen). |
| `group_ids` | `string[]` | Nein | `[]` | Liste zuzuordnender Gruppen-UUIDs. |
| `memory_enabled` | `boolean` | Nein | `false` | Hauptschalter für das Konversationsgedächtnis. |
| `memory_mode` | `string` | Nein | `"user_only"` | Verlauf-Filter: `"user_only"` oder `"all"`. |
| `memory_limit_type` | `string` | Nein | `"all"` | Kürzungstrategie: `"all"` oder `"message_count"`. |
| `memory_message_count` | `integer` | Nein | `null` | Max. behaltene Nachrichten (erforderlich, wenn der Limit-Typ `message_count` ist). |

**Antworten:**
- **`201 Created`**: Gibt das serialisierte Agenten-Dictionary zurück (`Agent.to_dict()`).
- **`400 Bad Request`**: Validierungsfehler, falls Pflichtfelder fehlen oder Einschränkungen verletzt wurden.

</details>

<details>
<summary><code>GET</code> <strong>/api/v1/agents</strong> — Alle Agenten auflisten</summary>

<br>

**Beschreibung:**  
Ruft alle registrierten Agenten ab, geordnet nach jüngster Aktivität.

**Antworten:**
- **`200 OK`**: Gibt ein JSON-Array von Agentenobjekten zurück.

</details>

<details>
<summary><code>PUT</code> <strong>/api/v1/agents/{agent_id}</strong> — Agenten aktualisieren</summary>

<br>

**Beschreibung:**  
Aktualisiert Metadaten, System-Prompts oder Speicherkonfigurationen für einen bestehenden Agenten.

**Pfadparameter:**
- `agent_id` (`string`): Eindeutige UUID des Agenten.

**Anfragetext (`UpdateAgentRequest`):** *(Alle Felder für partielle Aktualisierungen optional)*
```json
{
  "name": "Updated Assistant Name",
  "memory_message_count": 15
}
```

**Antworten:**
- **`200 OK`**: Gibt das aktualisierte Agenten-Dictionary zurück.
- **`404 Not Found`**: Agent existiert nicht.

</details>

<details>
<summary><code>DELETE</code> <strong>/api/v1/agents/{agent_id}</strong> — Agenten löschen</summary>

<br>

**Beschreibung:**  
Löscht einen Agenten und dessen zugehörige Datenquellen permanent.

**Pfadparameter:**
- `agent_id` (`string`): Eindeutige UUID des Agenten.

**Antworten:**
- **`204 No Content`**: Erfolgreich gelöscht.
- **`404 Not Found`**: Agent nicht gefunden.

</details>

## 3. Agenten-Gruppen-Endpunkte (`/api/v1/groups`)

Verwaltung von organisatorischen Agentengruppen.

<details>
<summary><code>POST</code> <strong>/api/v1/groups</strong> — Gruppe erstellen</summary>

<br>

**Anfragetext (`GroupRequest`):**
```json
{
  "name": "DevOps Squad",
  "description": "Agents specialized in CI/CD and infrastructure"
}
```

**Antworten:**
- **`201 Created`**: Gibt das erstellte Gruppenobjekt zurück.
- **`400 Bad Request`**: Validierungsfehler.

</details>

<details>
<summary><code>GET</code> <strong>/api/v1/groups</strong> — Alle Gruppen auflisten</summary>

<br>

**Antworten:**
- **`200 OK`**: Gibt ein Array aller Gruppen einschließlich der Mitgliederanzahl zurück.

</details>

<details>
<summary><code>PUT</code> <strong>/api/v1/groups/{group_id}</strong> — Gruppenmetadaten aktualisieren</summary>

<br>

**Anfragetext (`GroupRequest`):** Name und Beschreibung.  
**Antworten:** `200 OK`, `404 Not Found`.

</details>

<details>
<summary><code>DELETE</code> <strong>/api/v1/groups/{group_id}</strong> — Gruppe löschen</summary>

<br>

**Beschreibung:** Löscht den Gruppencontainer (Agentenzuordnungen werden entfernt, die Agenten selbst bleiben erhalten).  
**Antworten:** `204 No Content`, `404 Not Found`.

</details>

<details>
<summary><code>PUT</code> <strong>/api/v1/groups/{group_id}/agents</strong> — Agenten zu Gruppe zuweisen</summary>

<br>

**Anfragetext (`AssignAgentsRequest`):**
```json
{
  "agent_ids": ["uuid-agent-1", "uuid-agent-2"]
}
```

**Antworten:**
- **`200 OK`**: Zuordnungen erfolgreich aktualisiert.

</details>

## 4. Agenten-Wissensdatenbank & Datenquellen (`/api/v1/agents/{agent_id}/datasources`)

Referenzdokumente in die Wissensdatenbank eines Agenten hochladen.

<details>
<summary><code>POST</code> <strong>/api/v1/agents/{agent_id}/datasources</strong> — Datenquelle hochladen</summary>

<br>

**Beschreibung:**  
Lädt ein Dokument über `multipart/form-data` hoch und verknüpft es als Wissensquelle mit dem Agenten.

**Formularparameter:**
- `file` (File Blob, **Erforderlich**): Die Dokumentdatei (PDF, TXT, MD, JSON).
- `name` (string, Optional): Benutzerdefinierter Anzeigename.

**Antworten:**
- **`201 Created`**: Gibt das erstellte Datenquellen-Entitätsobjekt zurück.
- **`400 Bad Request`**: `NO_FILE_PART` oder `NO_SELECTED_FILE`.
- **`404 Not Found`**: Agent nicht gefunden.

</details>

<details>
<summary><code>DELETE</code> <strong>/api/v1/agents/{agent_id}/datasources/{datasource_id}</strong> — Datenquelle löschen</summary>

<br>

**Antworten:**
- **`200 OK`**: `{"message": "Datasource successfully deleted", "id": "..."}`
- **`404 Not Found`**: Agent oder Datenquelle nicht gefunden.

</details>

## 6. Echtzeit-Streaming & Chat (`/api/v1/agents/{agent_id}/stream`)

<details>
<summary><code>POST</code> <strong>/api/v1/agents/{agent_id}/stream</strong> — Agentenantwort streamen (SSE)</summary>

<br>

**Beschreibung:**  
Speichert eingehende Benutzernachrichten dauerhaft (mit optionalen Dateianhängen via `multipart/form-data` oder `application/json`) und streamt LLM-Ausführungstokens sowie Tool-Task-Chain-Ereignisse in Echtzeit über Server-Sent Events (SSE) zurück.

**Anfragetext (JSON-Beispiel):**
```json
{
  "text": "Fetch recent news and summarize them.",
  "conversation_id": "conv-uuid-1234"
}
```

| Feld | Typ | Erforderlich | Standard | Beschreibung |
| :--- | :--- | :--- | :--- | :--- |
| `text` oder `message` | `string` | Ja* | `""` | Benutzer-Prompt-Text. |
| `conversation_id` | `string` | Nein | `null` | Ziel-Konversations-UUID (wird bei Weglassen automatisch generiert). |
| `files` | `file[]` | Nein | `[]` | Optionale Dateianhänge (gesendet via `multipart/form-data`). |

*\* Entweder Text oder Dateien müssen bereitgestellt werden.*

**Antwort-Stream (W3C Server-Sent Events):**
```text
data: {"type": "meta", "data": {"conversation_id": "conv-uuid-1234", "user_message_id": "msg-999"}}

data: I am analyzing your request and planning the task chain...
data: • Step 1: Executing web search...
data: • Step 2: Summarizing results...

```

</details>

## 7. Sandboxed-Dateibereitstellung (`/api/v1/chat`)

<details>
<summary><code>GET</code> <strong>/api/v1/chat/conversations/{conversation_id}/files/{filename}</strong> — Sandbox-Datei herunterladen</summary>

<br>

**Beschreibung:**  
Stellt generierte Dateien (wie Berichte, ODF-Dokumente oder generierte Bilder) direkt aus dem Konversations-Sandbox-Ordner als Anhänge bereit.

**Pfadparameter:**
- `conversation_id` (`string`): Konversations-UUID.
- `filename` (`string`): Relativer Dateiname oder Pfad innerhalb des Konversations-Arbeitsbereichs.

**Antworten:**
- **`200 OK`**: Binärer Dateistream (`as_attachment=True`).
- **`404 Not Found`**: Datei existiert nicht.

</details>
